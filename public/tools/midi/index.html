    Pro Toolsへの読み込み

    1. Studio One 6からStandard MIDI File（.mid）を書き出します。
    2. ここで変換し、ダウンロードします。
    3. Pro Toolsの「File → Import → MIDI」で読み込み、テンポマップの取り込みを有効にしてください。既存セッションのテンポ・拍子が置き換わるため、取り込み先を確認してください。
    4. マーカーの取り込み設定があるバージョンでは有効にし、開始位置・テンポ・拍子・ノートを確認します。

    Format 1に統一し、テンポ・拍子・調号・SMPTEオフセット・マーカー・キューポイントを先頭トラックへ集約します。ノート、CC、プログラムチェンジ、ピッチベンド、SysEx、その他のメタ情報は元トラックに保持。音色・プラグイン・音声は変換対象外です。

    Pro Tools実機での読み込み成功を保証するものではありません。元MIDIは保管してください。Format 2、RMID、壊れたファイルは受け付けません。
