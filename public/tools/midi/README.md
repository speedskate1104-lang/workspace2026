# MIDI Tools — GOAT Workspace

Studio One 6で書き出したSMF MIDIをブラウザ内で解析し、Pro Tools向けにFormat 1へ整理する静的ツール。外部ライブラリ、ビルド、サーバーへのアップロードは不要。

## 使用方法

`public/tools/midi/index.html` を直接ブラウザで開くか、既存サイトの `/tools/midi/` にアクセスする。既存の `public/data/tools.json` にこのリンクは登録済みのため、既存ファイルの変更は不要。

1. `.mid` / `.midi` を選択またはドロップする。
2. 保持検証結果と警告を確認する。
3. `元ファイル名_protools.mid` をダウンロードする。
4. Pro Toolsの File → Import → MIDI で読み込み、テンポマップを取り込む。取り込み先セッションの既存テンポ・拍子を置換する点に注意。マーカー取り込みオプションがあれば有効にし、位置を確認する。

## 変換内容

- 入力はSMF Format 0 / 1。出力はFormat 1。
- テンポ (51)、拍子 (58)、調号 (59)、SMPTEオフセット (54)、マーカー (06)、キューポイント (07) を新しい先頭管理トラックへ集約。
- 元の各トラックを空トラックも含めて保持。イベントの絶対tick、元トラック終端、時間分解能、チャンネル、ノート、CC、プログラム、ピッチベンド、SysEx、その他メタイベントを保持。
- メタイベントの文字列を再エンコードしない。表示のみUTF-8として解釈し、文字化けしても出力バイト列は保持する。
- Running Statusを明示ステータスへ展開。各トラックにEnd of Trackを1件出力。欠落していた場合は警告して補完。
- 既定テンポ・拍子を挿入せず、重複イベントも削除しない。同時刻の異なるテンポ等や未終端ノートは警告する。自動的なノート補正、量子化、分解能変換は行わない。
- 出力を再解析して、移動した管理イベントの順序・時刻・内容と、元トラックごとの残りのイベントの順序・時刻・内容・終端位置を比較。一致しない場合はダウンロード不可。

## 対応範囲・制限

入力・出力は16 MiB以下、入力は500,000イベント以下。Format 2、RMID、未知チャンク、非標準ヘッダー、壊れた可変長数値、途中で切れたデータ、EOT以降のデータ等は情報欠落を避けるため拒否する。出力の上限超過やトラック数超過もエラーとする。SMPTE分解能はそのまま保持し警告する。

音声、音色、プラグイン、Studio One `.song` の変換には非対応。Pro Toolsのバージョン、文字コード、開始位置、インポート設定により読み込み結果は異なる。Studio One実書き出しファイルおよびPro Tools実機でのインポートは未検証で、成功保証はしない。元ファイルを保管する。

本ページは静的HTMLで、既存ダッシュボードのPHPログイン処理は呼び出さない。選択ファイルはネットワークへ送信しない。

## 構成

- `index.html`: ファイル選択、結果、インポート手順
- `style.css`: このページ専用のレスポンシブスタイル
- `midi.js`: DOM非依存のSMF解析・変換・保持検証
- `app.js`: 選択・ドロップ、検証結果表示、Blobダウンロード
- `../../../tests/midi.test.cjs`: Node.js標準テスト（追加パッケージ不要）

リポジトリ直下で `node --test tests/midi.test.cjs` を実行する。

検証済み: Format 0/1、Running Status、テンポ変更、拍子、マーカーの元バイト列、CC・プログラム・ベンド、F0/F7 SysEx、未知メタ、SMPTE、複数byteデルタ、EOT補完、競合警告、破損入力拒否、改変検出、50,000イベントの書き出し。ChromeでローカルHTMLの選択・変換・ダウンロード結果の保持検証、不正ファイル時のダウンロード無効化、マーカー文字列のHTML非実行、390px画面の横はみ出しなしも確認。
